# Cenário 2
##  Vulnerabilidade de Segurança Descoberta em uma Dependência de Terceiros
### Uma vulnerabilidade crítica é descoberta em uma biblioteca de terceiros usada pelo aplicativo, permitindo ataques de hackers para acessar dados sensíveis dos usuários

* Probabilidade
C
* Impacto
5
* Matriz de Risco
C5 - Muito Alto
* Testes Utilizados
Teste Funcional, Teste de Regressão, Teste Automatizado
* Estratégia de Mitigação
Substituir dependências por soluções internas, delay na atualização para versões novas das dependências, somente após análise. 
* Tipos de Risco
Negócio
