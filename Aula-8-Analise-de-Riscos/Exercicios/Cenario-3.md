# Cenário 3
##  Erro de Interface do Usuário que Causa Confusão entre os Usuários
### Uma alteração na interface do usuário causa confusão entre os usuários, mas não afeta a funcionalidade básica do aplicativo.

* Probabilidade
D
* Impacto
2
* Matriz de Risco
D2 - Médio
* Testes Utilizados
Teste Funcional, Teste de Usabilidade
* Estratégia de Mitigação
Aplicar as mudanças com um número pequeno de usuários antes do público geral, coletando feedbacks negativos caso existam.
* Tipos de Risco
Humano
