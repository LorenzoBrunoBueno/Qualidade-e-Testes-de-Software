# Contextos Históricos

Surge para garantir que o software funcione como o esperado e atenda as necessidades do usuário.


- 1878
O termo bug surge devido a um problema de leitura causado pela presença de um inseto no fonógrafo (primeiro dispositivo para captação e reprodução de som mecanicamente) de Thomas Edson, que passou a chamar defeitos industriais de bug.

- 1947 
Primeiro bug de computador encontrado, onde um inseto presente nos circuitos do computador Harvard Mark estava causando erros nos cálculos.

- 1979
Lançado o livro "The art of software testing", que apresentava técnicas e conhecimentos avançados para teste de softwares da época.

- 1980
Primeiras ferramentas para testes funcionais através de scripts entre outras ferramentas para gerenciamento de testes.

- 1995
Surgem ferramentas para teste automatizado de performance.

- 2002
Surge a ALATS no Brasil, uma organização que tem o objetivo de aprimorar os processos de testes dos softwares, reunindo profissionais para propor melhorias e troca de informações.

- 2006

A ISTQB chega ao Brasil, disponibilizando a certificação ISTQB adaptada ao público Brasileiro.

- Hoje

A área da Qualidade de Software segue evoluíndo com a base sólida da atualidade, unindo padrões de qualidade e metodologias com automação DevOps e Inteligência Artificial.
